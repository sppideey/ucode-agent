# Code of conduct

ucode follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be kind, be constructive, and assume good faith. Harassment, insults and
personal attacks are not welcome in issues, discussions or pull requests.

Report a problem privately to the maintainer through
[GitHub](https://github.com/sppideey). Reports are kept confidential.
